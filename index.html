✨ Key Features

Lightning Fast

512KB chunked processing ensures memory-efficient downloads even for large backup files.

Real-Time Progress

Monitor download speed, time remaining, elapsed time, and file size in real-time.

Secure & Safe

WordPress nonce verification, capability checks, and URL validation ensure security.

Easy to Use

Simple interface - just paste the URL and click upload. No complex configuration needed.

Comprehensive Debugging

Console logging and server logs make troubleshooting easy and transparent.

No Size Limits

Upload files of any size - only limited by your server configuration, not the plugin.

📦 Installation

1

Download Plugin

Click the download button above to get the latest version from GitHub releases.

2

Upload to WordPress

Go to Plugins → Add New → Upload Plugin in your WordPress admin.

3

Activate Plugin

After installation, click Activate Plugin to enable it.

4

Start Uploading

Navigate to Tools → Remote File Uploader and start uploading your backup files!

⚙️ Technical Specifications

Buffer Size 512KB (524,288 bytes)
Memory Limit 512MB (configurable)
Execution Time Unlimited for large files
Progress Updates Every 0.5 seconds
WordPress Version 5.0 or higher
PHP Version 7.2 or higher
